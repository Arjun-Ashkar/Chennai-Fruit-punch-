# Chennai Fruit Punch

A responsive menu website for Chennai Fruit Punch, featuring fresh juices, shakes, falooda, snacks, burgers, and quick contact actions.

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite in your browser.

## Production Build

```bash
npm run build
```

The production files are generated in `dist/`.

## Image Sources

Menu and website images are loaded from Unsplash and Pexels. Review the original source pages and their current license terms before commercial publication. The local `src/assets/hero.png` image should only be published if you own it or have permission to use it.
